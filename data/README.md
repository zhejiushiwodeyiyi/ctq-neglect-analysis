# Local questionnaire input

Participant-level data are not distributed in this repository. The unchanged statistical entry points expect the authorized corrected file at `data/questionnaire_analysis.csv`. Its schema and original scoring provenance must be obtained from the data custodian and the full research package.

Do not commit questionnaires, participant or school identifiers, raw exports or recordings. `.gitignore` excludes this directory except for this README, but Git ignore rules do not replace authorization or review of the files being uploaded.
